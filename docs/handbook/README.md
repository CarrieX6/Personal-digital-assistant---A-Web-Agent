## 三个不同的“成功”

1. Agent Run 完成：已经回答，或已经成功提交后台任务。
2. 图像 Job 完成：模型和后处理产生了可用 Asset。
3. 渠道交付成功：结果确实被平台接受，且手机能够打开/消费。

因此 `AgentRun.status=completed` 不能单独证明图片生成完成；Job 完成也不能证明飞书回传成功。
同样，`/health=ok` 只说明 API 能响应，不表示模型/飞书/Viewer 全部可用。

## 开始前的安全约定

- 只在有权限的电脑、飞书应用和 GitHub 仓库操作。
- 先以本机模式运行，不直接把 3000/8000 的 Root API 暴露到公网。
- 不向聊天、Issue、截图或 Git 提交 API Key、App Secret、数据库、个人照片和签名链接。
- 安装器的许可证确认由部署者决定；模型许可不能由 LLM 代替接受。
- 迁移必须备份数据和相关密钥。克隆代码不会自动迁移模型、Secret、记忆和资产。
