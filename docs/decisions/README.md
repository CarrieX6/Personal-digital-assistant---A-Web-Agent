# 技术决策记录

作者：**Zhuofan Xie**

本目录保存 Architecture Decision Record（ADR）。ADR 记录已经作出的重要技术选择、
选择原因、代价和重新评估条件，不替代调研文档和实验记录。

## 状态

- `Proposed`：建议方案，尚未批准；
- `Accepted`：当前生效；
- `Superseded`：已被新 ADR 替代；
- `Deprecated`：不再推荐，但尚未完全移除；
- `Rejected`：经过评估后不采用。
