## 规则

- 不提交 API Key、个人图片、未授权数据或模型权重；
- 原始结果过大时记录生成方式、哈希和本地保存位置，不提交文件本体；
- 必须记录失败结果，不能只保留效果最好的样本；
- 上游报告与本项目实测分开；
- 性能结果必须注明设备、电源模式、运行时和模型版本。
