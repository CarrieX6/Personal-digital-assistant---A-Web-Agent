# 学习笔记

作者：**Zhuofan Xie**

本目录用于保存团队学习过程中的知识总结。笔记要服务于代码和决策，避免只复制
教程内容。

## 建议学习顺序

1. **Web Agent 基础**
   - Tool Calling；
   - Agent loop；
   - JSON Schema；
   - Prompt injection 与工具权限。
2. **异步系统**
   - 任务队列；
   - 幂等；
   - 重试与取消；
   - 进度事件。
3. **外部消息平台**
   - Webhook 与 WebSocket；
   - 事件验签；
   - OAuth / tenant token；
   - 消息卡片和媒体上传。
4. **记忆系统**
   - 会话记忆与长期记忆；
   - 检索；
   - 摘要；
   - 删除与数据治理。
5. **端侧 AI**
   - MPS、CUDA、CPU 调度；
   - 模型量化；
   - 显存和能耗；
   - 模型许可。
6. **空间内容**
   - 单目深度；
   - LDI / MPI；
   - Three.js；
   - 3DGS 与移动端 Viewer。
