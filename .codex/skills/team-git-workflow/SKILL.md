# 团队 Git 协作 / Team Git Workflow

作者：**Zhuofan Xie**

## 选择语言 / Select Language

1. 用户明确指定语言时，使用指定版本。
2. 未指定时，跟随当前会话语言；无法判断时默认使用中文。
3. 中文流程读取
   [`references/workflow.zh-CN.md`](references/workflow.zh-CN.md)。
4. English workflow: read
   [`references/workflow.en.md`](references/workflow.en.md).
5. 除非用户要求翻译或对照，否则只读取一个语言版本，避免重复占用上下文。

## 按需读取模板 / Load Templates When Needed

- 创建或评审 PR、交接任务、记录复杂冲突时，中文读取
  [`references/templates.zh-CN.md`](references/templates.zh-CN.md)。
- When creating or reviewing a PR, handing off work, or recording a complex
  conflict in English, read
  [`references/templates.en.md`](references/templates.en.md).

无论使用哪种语言，都必须遵循同一套分支、安全、验证、评审与合并边界，不得因翻译
版本不同而改变规则。
